# Análisis Exploratorio de Datos (EDA) - Comportamiento de Usuarios en Spotify

Este proyecto realiza un análisis exploratorio reproducible sobre un dataset de 50.000 usuarios de Spotify.

## Requisitos y Entorno
- **Python**: Versión 3.9 o superior.
- **Dependencias**: Listadas en `requirements.txt`.
